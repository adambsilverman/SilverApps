Key ideas
  1. Number: count letter names, including both notes (C up to E = C D E = a 3rd).
  2. Quality: count half steps. Major 3rd = 4, perfect 5th = 7, octave = 12.
  3. Spelling matters: a 3rd always spans three letters, so C–E♭ is a minor 3rd but C–D♯ is an augmented 2nd.
