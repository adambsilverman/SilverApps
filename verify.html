Interactive Music Training

Check reports

Paste one report or many: completion reports from the practice apps and quiz reports from the Test Yourself quizzes. You can also choose the report files students downloaded. Each report's verification code is checked, which shows whether its numbers were changed after it was made. It's a deterrent, not cryptographic proof.

Gradebook import file

Makes a file your LMS can import, with one grade column per lesson or app. Only reports that check out are included. If a student sent more than one report for the same quiz, the best score is used. Students are matched by the Student ID or username they typed in the report, so ask them to use the ID your LMS knows (campus username, or for Brightspace the OrgDefinedId). Setup steps for each LMS are on About this site.
