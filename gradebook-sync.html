Gradebook sync

Every lesson's Test Yourself quiz can send its score to your course gradebook. Download a SCORM package for a quiz here and add it to your course in D2L Brightspace, Canvas, Blackboard or Moodle. Students open the quiz from inside the course; when they finish, their first-try score (as a percent) goes into the gradebook. If they take it again, the gradebook keeps their best score.

The package is tiny: it holds no lesson content, just a page that shows the live quiz from this site and passes the score along. Updates to the lesson reach your students without a new upload. Step-by-step setup for each LMS is on About this site.

Want one test covering several units, without hints? The Test maker builds one from these same question banks and makes a SCORM package for it too.

No LMS, or you'd rather not upload anything? Students can press Report for my professor at the end of any quiz and send you a report with a verification code. Paste a stack of them into Check reports to verify them and download a gradebook import file.

Download a SCORM package

The packages are SCORM 1.2, which every major LMS accepts. Upload each quiz's package separately; each one becomes its own gradebook item.

Skill Tests: one package for all of them

The Skill Tests (on the front page, a Skill Test button on the card of the lesson each one checks) are drills with a finish line: 20 fresh questions, with 80% counting as mastery. The Skill Mastery package puts all eight in one gradebook item. Inside it, students see every test with their best score so far and choose one to take. Each skill counts as the student's best score on its test (a test not taken yet counts 0), and the grade is the average of all of them, so retaking a test can only raise it.

Give its grade item any point value (one point per skill makes each skill worth 1). The package also marks the item completed once every skill has been tried and passed once all eight are mastered.

Or: one package per Skill Test (mastery, all or nothing)

These report all or nothing, one grade item per skill. The gradebook shows 100% once a student has mastered the skill and 0% before that, and a later, lower try never takes it away. Attach each package to a grade item worth 1 point (or any value) and a mastered skill earns full credit for that item. Students can retake a test as often as they like, with new questions every time.

The packages use the site address above. D2L Brightspace: after importing each package, set its grade item to 1 point; a checklist or release conditions can then use "Grade value on a grade item is at least 1" (see About this site).
