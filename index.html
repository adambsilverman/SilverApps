SilverApps for Music Training

Apps for review, practice and skill building in music theory, ear training and performance. Each topic has an interactive lesson, drills with instant feedback, or both. Every drill can also run live as a class game on student devices.

For instructors: running a class game
  • Practice soloOpen any drill and start: it explains each answer and brings missed items back for review.
  • Host a class gameOn the projector, open a drill and choose Host a class game. You pick each question; the class answers anonymously.
  • Join from any deviceOn a phone, tablet or laptop, open the same drill, tap Join a game, and enter the room code (or scan the QR code).

Students can also make a completion report in any drill (“Your progress” panel). Check a student's report.
